# 🔌 Sunotal REST API Reference & Contracts

Complete API specification for Storefront, Farmer/Vendor Portal, Admin Control Center, and Delivery Partner App endpoints.

Base Path: `/api`

---

## 1. Authentication Endpoints

### `POST /api/auth/register`
Registers a new customer, vendor, or delivery partner account.
- **Request Body**:
  ```json
  {
    "name": "Ananya Roy",
    "email": "ananya@example.com",
    "password": "SecurePassword123!",
    "role": "customer"
  }
  ```
- **Response** (`201 Created`):
  ```json
  {
    "id": 101,
    "name": "Ananya Roy",
    "email": "ananya@example.com",
    "token": "eyJhbGciOiJIUzI1Ni..."
  }
  ```

### `POST /api/auth/login`
Authenticates a user and issues a JWT token.

---

## 2. Products & Grocery Catalog

### `GET /api/products`
Retrieves products filtered by category, search query, or dark store location.
- **Query Parameters**: `category`, `search`, `limit`, `offset`
- **Response**: Array of product objects containing unit weight (`500 g`, `1 L`), price, original price, discount percentage, and stock level.

---

## 3. Dark Store Inventory & Warehouse Allocation

### `GET /api/inventory/dark-stores`
Returns local Dark Stores with status and stock availability.

### `POST /api/inventory/allocate`
Allocates item inventory for 10-15 min express order packing.

---

## 4. Checkout & Payments (SOLID Payment Engine)

### `POST /api/orders`
Creates a new grocery order.
- **Request Body**:
  ```json
  {
    "items": [{ "productId": 4, "quantity": 2 }],
    "deliveryAddress": {
      "street": "Green Glen Layout",
      "city": "Bengaluru",
      "pincode": "560103",
      "lat": 12.9352,
      "lng": 77.6245
    },
    "paymentMethod": "upi_qr",
    "deliverySlot": "express_10_15_mins"
  }
  ```

### `POST /api/payments/verify`
Verifies payment transaction generated by `IPaymentProvider` strategy.

---

## 5. Delivery Partner Endpoints

### `GET /api/delivery/alerts`
Returns pending hyperlocal order alerts within 3 km radius of rider.

### `POST /api/delivery/accept`
Accepts order dispatch with 30s timer.

### `POST /api/delivery/payout-request`
Triggers instant rider earnings payout to UPI / Bank Account.
